Get Started in Minutes

Just two steps to integrate Country-Picker into your app

1

Add the dependency

dependencies {
    implementation("com.github.arpitkatiyar1999:Country-Picker:2.1.5")
}
2

Use it in your Compose function

@Composable
fun MyScreen() {
    var selectedCountry by remember { mutableStateOf(null) }

    CountryPicker(
        onCountrySelected = { country ->
            selectedCountry = country
        }
    )
}

That's it! You're ready to go. 🎉
