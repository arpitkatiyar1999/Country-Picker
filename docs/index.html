Country-Picker

A beautiful, customizable Jetpack Compose library for country code selection with phone number validation

Get Started View on GitHub
Version 2.1.5 Material 3 API 21+

Overview

Country-Picker is a lightweight, feature-rich Android library built with Jetpack Compose that provides an elegant solution for country code selection and phone number validation. It seamlessly integrates with Material 3 design principles and supports both Dialog and BottomSheet display modes.

Requirements: This library requires Material 3 version 1.3.0 or later to work properly.

Quick Start

1. Add Dependency

Add JitPack repository to your settings.gradle:

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven(url = "https://jitpack.io")
    }
}

Add the dependency in your module-level build.gradle:

dependencies {
    implementation("com.github.arpitkatiyar1999:Country-Picker:2.1.5")
}

2. Basic Usage

Use CountryPicker in your Compose function:

@Composable
fun MyScreen() {
    var selectedCountry by remember { mutableStateOf(null) }

    CountryPicker(
        onCountrySelected = { country ->
            selectedCountry = country
            println("Selected: ${country.countryName} (${country.countryPhoneNumberCode})")
        }
    )
}

3. With Text Field

For phone number input with validation:

@Composable
fun PhoneNumberInput() {
    var phoneNumber by remember { mutableStateOf("") }
    var selectedCountry by remember { mutableStateOf(null) }

    CountryPickerOutlinedTextField(
        mobileNumber = phoneNumber,
        onMobileNumberChange = { phoneNumber = it },
        onCountrySelected = { selectedCountry = it },
        label = { Text("Phone Number") }
    )
}
That's it! You now have a fully functional country picker with phone number validation.

Main Components

CountryPicker

A standalone country picker that displays the selected country with its flag, phone code, and optional country name or code. Perfect for forms where you need country selection without a text field.

Learn more →

CountryPickerOutlinedTextField

Combines the country picker with a Material 3 OutlinedTextField for phone number input. Includes built-in validation and formatting capabilities.

Utility Functions

The library provides powerful utility functions for phone number operations:

Function Description
isMobileNumberValid() Validates a mobile number for a specific country
getExampleMobileNumber() Returns an example number for a country (formatted or raw)
getFormattedMobileNumber() Formats a mobile number according to country rules

Display Modes

Choose between two elegant display modes for the country list:

Dialog

Traditional modal dialog centered on screen

CountryPicker(
    countryListDisplayType = CountryListDisplayType.Dialog
)

BottomSheet

Modern bottom sheet that slides up from bottom

CountryPicker(
    countryListDisplayType = CountryListDisplayType.BottomSheet
)
