Getting Started

This guide will help you integrate Country-Picker into your Android project in just a few minutes.

Prerequisites

Before you begin, ensure your project meets these requirements:

Requirement Minimum Version
Android API Level 21 (Android 5.0 Lollipop)
Compile SDK 36 (recommended)
Jetpack Compose Material 3 1.3.0
Kotlin 1.8+
Important: This library requires Material 3 version 1.3.0 or later. If you're using the Compose BOM, check the BOM mapping to verify your Material 3 version.

Installation

Step 1: Add JitPack Repository

Add the JitPack repository to your settings.gradle.kts (or settings.gradle for Groovy): 

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven(url = "https://jitpack.io")  // Add this line
    }
}
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }  // Add this line
    }
}

Step 2: Add Library Dependency

Add the Country-Picker dependency to your module-level build.gradle.kts (usually in the app folder): 

dependencies {
    // Other dependencies...

    // Country-Picker
    implementation("com.github.arpitkatiyar1999:Country-Picker:2.1.5")
}
dependencies {
    // Other dependencies...

    // Country-Picker
    implementation 'com.github.arpitkatiyar1999:Country-Picker:2.1.5'
}
Latest Version: Check GitHub Releases for the most recent version.

Step 3: Sync Project

Click "Sync Now" in the banner that appears, or select File > Sync Project with Gradle Files in Android Studio.

Verify Installation

To verify the library is installed correctly, try importing the components:

import com.arpitkatiyarprojects.countrypicker.CountryPicker
import com.arpitkatiyarprojects.countrypicker.CountryPickerOutlinedTextField
import com.arpitkatiyarprojects.countrypicker.models.CountryDetails
import com.arpitkatiyarprojects.countrypicker.utils.CountryPickerUtils

If the imports resolve without errors, you're ready to go! 🎉

Your First Country Picker

Let's create a simple example to get you started:

Basic CountryPicker

@Composable
fun MyFirstPicker() {
    var selectedCountry by remember { mutableStateOf(null) }

    Column(modifier = Modifier.padding(16.dp)) {
        // Country Picker
        CountryPicker(
            onCountrySelected = { country ->
                selectedCountry = country
            }
        )

        // Display selected country
        selectedCountry?.let {
            Spacer(modifier = Modifier.height(16.dp))
            Text("Selected: ${it.countryName}")
            Text("Phone Code: ${it.countryPhoneNumberCode}")
            Text("ISO Code: ${it.countryCode.uppercase()}")
        }
    }
}

With Phone Number Input

@Composable
fun PhoneNumberForm() {
    var phoneNumber by remember { mutableStateOf("") }
    var selectedCountry by remember { mutableStateOf(null) }

    Column(modifier = Modifier.padding(16.dp)) {
        CountryPickerOutlinedTextField(
            mobileNumber = phoneNumber,
            onMobileNumberChange = { phoneNumber = it },
            onCountrySelected = { selectedCountry = it },
            label = { Text("Phone Number") },
            placeholder = {
                Text("Enter your phone number")
            }
        )

        // Validation
        selectedCountry?.let { country ->
            val isValid = CountryPickerUtils.isMobileNumberValid(
                phoneNumber,
                country.countryCode
            )

            Spacer(modifier = Modifier.height(8.dp))
            Text(
                text = if (isValid) "✓ Valid number" else "✗ Invalid number",
                color = if (isValid) Color.Green else Color.Red
            )
        }
    }
}
Success! You now have a working country picker. Continue to the next sections to explore customization options and advanced features.

Basic Configuration

Setting Default Country

You can specify a default country using its ISO 3166-1 alpha-2 code:

CountryPicker(
    defaultCountryCode = "US",  // United States
    onCountrySelected = { country -> /* ... */ }
)

// Other examples:
// "IN" for India
// "GB" for United Kingdom
// "CA" for Canada
// "AU" for Australia
If no default country is specified, the library will automatically detect the user's country from their SIM card using TelephonyManager.

Limiting Country List

Restrict the picker to specific countries:

CountryPicker(
    countriesList = listOf("US", "CA", "MX"),  // North America only
    onCountrySelected = { country -> /* ... */ }
)

// Or for European countries:
// countriesList = listOf("GB", "FR", "DE", "IT", "ES")

Choosing Display Mode

Select between Dialog and BottomSheet:

import com.arpitkatiyarprojects.countrypicker.enums.CountryListDisplayType

// Dialog mode (default)
CountryPicker(
    countryListDisplayType = CountryListDisplayType.Dialog,
    onCountrySelected = { country -> /* ... */ }
)

// BottomSheet mode
CountryPicker(
    countryListDisplayType = CountryListDisplayType.BottomSheet,
    onCountrySelected = { country -> /* ... */ }
)

Troubleshooting

❌ Material 3 version error

Problem: Getting errors about Material 3 compatibility

Solution: Ensure you're using Material 3 version 1.3.0 or later:

dependencies {
    implementation("androidx.compose.material3:material3:1.3.0")
    // Or use BOM:
    implementation(platform("androidx.compose:compose-bom:2024.02.00"))
}

❌ JitPack build failed

Problem: Dependency resolution fails

Solution: Make sure you added JitPack to repositories in settings.gradle, not in module-level build.gradle

❌ Country not auto-detecting

Problem: Default country not detected automatically

Solution: This feature requires a SIM card. On emulators or devices without SIM, manually specify defaultCountryCode

❌ Phone validation not working

Problem: isMobileNumberValid() always returns false

Solution: Make sure you're passing the mobile number WITHOUT the country phone code:

// ✗ Wrong
CountryPickerUtils.isMobileNumberValid("+1234567890", "US")

// ✓ Correct
CountryPickerUtils.isMobileNumberValid("234567890", "US")
