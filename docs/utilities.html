Utility Functions

CountryPickerUtils provides powerful functions for phone number validation, formatting, and example generation using Google's libphonenumber library.

Import: import com.arpitkatiyarprojects.countrypicker.utils.CountryPickerUtils

isMobileNumberValid()

Validates a mobile number for a specific country using Google's libphonenumber library.

Signature

fun isMobileNumberValid(
    mobileNumber: String,
    countryCode: String
): Boolean

Parameters

ParameterTypeDescription
mobileNumberStringThe mobile number to validate (without country phone code)
countryCodeStringISO 3166-1 alpha-2 country code (e.g., "US", "IN", "GB")

Returns

Boolean - true if valid, false otherwise

Examples

// Valid numbers
val isValid1 = CountryPickerUtils.isMobileNumberValid("2025550123", "US")
// Returns: true

val isValid2 = CountryPickerUtils.isMobileNumberValid("7911123456", "GB")
// Returns: true

val isValid3 = CountryPickerUtils.isMobileNumberValid("9876543210", "IN")
// Returns: true

// Invalid numbers
val isValid4 = CountryPickerUtils.isMobileNumberValid("123", "US")
// Returns: false (too short)

val isValid5 = CountryPickerUtils.isMobileNumberValid("12345678901234567890", "US")
// Returns: false (too long)
Important: Do NOT include the country phone code in the mobile number. 
// ✗ Wrong
isMobileNumberValid("+1 202 555 0123", "US")

// ✓ Correct
isMobileNumberValid("2025550123", "US")

Use Cases

  • ✅ Form validation before submission
  • ✅ Real-time validation as user types
  • ✅ Verifying phone numbers from API responses
  • ✅ Checking phone number validity before SMS/call

getExampleMobileNumber()

Retrieves an example mobile number for a given country, optionally formatted.

Signature

fun getExampleMobileNumber(
    countryCode: String,
    formatNumber: Boolean = false
): String

Parameters

ParameterTypeDefaultDescription
countryCodeString-ISO 3166-1 alpha-2 country code
formatNumberBooleanfalseIf true, returns formatted number; otherwise raw

Returns

String - Example number, or empty string if unavailable

Examples

// Raw format
val rawUS = CountryPickerUtils.getExampleMobileNumber("US", formatNumber = false)
// Returns: "2015550123"

val rawGB = CountryPickerUtils.getExampleMobileNumber("GB", formatNumber = false)
// Returns: "7400123456"

// Formatted
val formattedUS = CountryPickerUtils.getExampleMobileNumber("US", formatNumber = true)
// Returns: "201 555 0123"

val formattedGB = CountryPickerUtils.getExampleMobileNumber("GB", formatNumber = true)
// Returns: "7400 123456"

val formattedIN = CountryPickerUtils.getExampleMobileNumber("IN", formatNumber = true)
// Returns: "99876 54321"

Use Cases

  • ✅ Showing placeholder examples in input fields
  • ✅ Displaying format hints to users
  • ✅ Testing phone validation logic
  • ✅ Generating sample data for UI previews

Practical Example

@Composable
fun PhoneInputWithExample() {
    var phoneNumber by remember { mutableStateOf("") }
    var selectedCountry by remember { mutableStateOf(null) }

    CountryPickerOutlinedTextField(
        mobileNumber = phoneNumber,
        onMobileNumberChange = { phoneNumber = it },
        onCountrySelected = { selectedCountry = it },
        placeholder = {
            selectedCountry?.let { country ->
                Text(
                    text = "e.g., ${CountryPickerUtils.getExampleMobileNumber(
                        country.countryCode,
                        formatNumber = true
                    )}"
                )
            }
        }
    )
}

getFormattedMobileNumber()

Formats a mobile number according to the country's specific formatting rules.

Requirement: This function should only be called AFTER validating the number with isMobileNumberValid(). It will return the original number unchanged if invalid.

Signature

fun getFormattedMobileNumber(
    mobileNumber: String,
    countryCode: String
): String

Parameters

ParameterTypeDescription
mobileNumberStringThe raw mobile number to format
countryCodeStringISO 3166-1 alpha-2 country code

Returns

String - Formatted number if valid, original number if invalid or on error

Examples

// US formatting
val formatted1 = CountryPickerUtils.getFormattedMobileNumber("2025550123", "US")
// Returns: "202 555 0123"

// UK formatting
val formatted2 = CountryPickerUtils.getFormattedMobileNumber("7911123456", "GB")
// Returns: "7911 123456"

// India formatting
val formatted3 = CountryPickerUtils.getFormattedMobileNumber("9876543210", "IN")
// Returns: "98765 43210"

// Invalid number - returns as-is
val formatted4 = CountryPickerUtils.getFormattedMobileNumber("123", "US")
// Returns: "123" (unchanged)

Use Cases

  • ✅ Displaying phone numbers in UI after validation
  • ✅ Formatting numbers for database storage
  • ✅ Auto-formatting as user types (with TextFieldValue)
  • ✅ Preparing numbers for display in lists or profiles

Real-Time Formatting Example

@Composable
fun AutoFormattingPhoneInput() {
    var phoneNumber by remember { mutableStateOf(TextFieldValue("")) }
    var selectedCountry by remember { mutableStateOf(null) }

    CountryPickerOutlinedTextField(
        mobileNumber = phoneNumber,
        onMobileNumberChange = { newValue ->
            selectedCountry?.let { country ->
                // Auto-format as user types
                if (CountryPickerUtils.isMobileNumberValid(newValue.text, country.countryCode)) {
                    val formatted = CountryPickerUtils.getFormattedMobileNumber(
                        newValue.text,
                        country.countryCode
                    )
                    phoneNumber = newValue.copy(
                        text = formatted,
                        selection = TextRange(formatted.length)
                    )
                } else {
                    phoneNumber = newValue
                }
            } ?: run {
                phoneNumber = newValue
            }
        },
        onCountrySelected = { selectedCountry = it }
    )
}

Complete Validation Workflow

Here's a comprehensive example combining all utility functions:

@Composable
fun CompletePhoneValidation() {
    var phoneNumber by remember { mutableStateOf("") }
    var selectedCountry by remember { mutableStateOf(null) }
    var isValid by remember { mutableStateOf(false) }
    var errorMessage by remember { mutableStateOf(null) }

    LaunchedEffect(phoneNumber, selectedCountry) {
        selectedCountry?.let { country ->
            when {
                phoneNumber.isEmpty() -> {
                    isValid = false
                    errorMessage = null
                }
                CountryPickerUtils.isMobileNumberValid(phoneNumber, country.countryCode) -> {
                    isValid = true
                    errorMessage = null
                }
                else -> {
                    isValid = false
                    errorMessage = "Invalid phone number for ${country.countryName}"
                }
            }
        }
    }

    Column(modifier = Modifier.padding(16.dp)) {
        CountryPickerOutlinedTextField(
            mobileNumber = phoneNumber,
            onMobileNumberChange = { phoneNumber = it },
            onCountrySelected = { selectedCountry = it },
            label = { Text("Phone Number") },
            placeholder = {
                selectedCountry?.let { country ->
                    Text(
                        "e.g., ${CountryPickerUtils.getExampleMobileNumber(
                            country.countryCode,
                            formatNumber = true
                        )}"
                    )
                }
            },
            isError = phoneNumber.isNotEmpty() && !isValid,
            supportingText = {
                when {
                    errorMessage != null -> Text(
                        text = errorMessage!!,
                        color = MaterialTheme.colorScheme.error
                    )
                    isValid -> Text(
                        text = "✓ Valid phone number",
                        color = Color(0xFF10B981)
                    )
                    else -> Text("Enter your phone number")
                }
            }
        )

        // Display formatted number
        if (isValid && selectedCountry != null) {
            Spacer(modifier = Modifier.height(16.dp))
            Card(
                modifier = Modifier.fillMaxWidth(),
                colors = CardDefaults.cardColors(
                    containerColor = Color(0xFFEFF6FF)
                )
            ) {
                Column(modifier = Modifier.padding(16.dp)) {
                    Text(
                        text = "Formatted Number",
                        style = MaterialTheme.typography.labelMedium,
                        color = Color(0xFF1E40AF)
                    )
                    Text(
                        text = "${selectedCountry!!.countryPhoneNumberCode} ${
                            CountryPickerUtils.getFormattedMobileNumber(
                                phoneNumber,
                                selectedCountry!!.countryCode
                            )
                        }",
                        style = MaterialTheme.typography.titleMedium,
                        fontWeight = FontWeight.Bold,
                        color = Color(0xFF1E3A8A)
                    )
                }
            }
        }
    }
}

Best Practices

✅ Always Validate Before Formatting

// ✓ Correct
if (CountryPickerUtils.isMobileNumberValid(number, country)) {
    val formatted = CountryPickerUtils.getFormattedMobileNumber(number, country)
    // Use formatted number
}

✅ Use Example Numbers in Placeholders

placeholder = {
    Text("e.g., ${CountryPickerUtils.getExampleMobileNumber(countryCode, true)}")
}

✅ Handle Empty State

LaunchedEffect(phoneNumber, selectedCountry) {
    if (phoneNumber.isNotEmpty() && selectedCountry != null) {
        // Validate only when both are available
    }
}

⚠️ Don't Pass Country Phone Code to Validation

// ✗ Wrong
isMobileNumberValid("+1 202 555 0123", "US")
isMobileNumberValid("1 202 555 0123", "US")

// ✓ Correct
isMobileNumberValid("2025550123", "US")

Error Handling

All utility functions handle errors gracefully:

FunctionOn Error
isMobileNumberValid()Returns false
getExampleMobileNumber()Returns "" (empty string)
getFormattedMobileNumber()Returns original mobileNumber unchanged
Note: Errors are logged internally using LoggerHelper but won't crash your app.
