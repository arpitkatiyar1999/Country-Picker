Installation

Add Country-Picker to your Android project in just a few steps.

Prerequisites

Before you begin, ensure your project meets these requirements:

Requirement Minimum Version
Android API Level 21 (Android 5.0 Lollipop)
Compile SDK 36 (recommended)
Jetpack Compose Material 3 1.4.0
Kotlin 1.9.0+ (Recommended: 2.0.0+)
Important: This library requires Material 3 version 1.4.0 or later. If you're using the Compose BOM, check the BOM mapping to verify your Material 3 version.

Step 1: Add JitPack Repository

Add the JitPack repository to your settings.gradle.kts (or settings.gradle for Groovy):

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven(url = "https://jitpack.io")  // Add this line
    }
}
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }  // Add this line
    }
}

Step 2: Add Library Dependency

Add the Country-Picker dependency to your module-level build.gradle.kts (usually in the app folder):

dependencies {
    // Other dependencies...

    // Country-Picker
    implementation("com.github.arpitkatiyar1999:Country-Picker:2.1.5")
}
dependencies {
    // Other dependencies...

    // Country-Picker
    implementation 'com.github.arpitkatiyar1999:Country-Picker:2.1.5'
}
Latest Version: Check GitHub Releases for the most recent version.

Step 3: Sync Project

Click "Sync Now" in the banner that appears, or select File > Sync Project with Gradle Files in Android Studio.

✅ That's it! You're ready to go. Start using Country-Picker in your app.
